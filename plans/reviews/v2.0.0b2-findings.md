# b2 findings

All results below use the source/environment in [preflight](v2.0.0b2-preflight.md).
Tests are in `tests/test_b2_reproductions.py`. Strict expected failures assert
desired invariants and must be removed in their repair commits. They are not
permission to freeze defects into the corrected reference.

| Finding | Executed evidence | Disposition |
| --- | --- | --- |
| F1 | Instrumented package driver with a real default-executor thread; cancelling caller and helper produces `cleanup` before `last native access`. Actual `asyncio.run()` shutdown in a child process produces the same order | Reproduced; WP1 blocker. Real codec integration and broader cancellation matrix still required |
| F2 | Custom async source consumes gzip(A), suspends, then is cancelled; retry successfully returns only `member B\n`. Actual aiofiles 25.1.0 executor-backed buffered file read likewise returns only `native member B\n` | Reproduced; WP2 blocker. Seek recovery and wider source matrix still required |
| F3 | Two gated path opens acquire two fake resources; close counts are `[0, 1]` before test cleanup | Reproduced; WP3 blocker. Native acquisition, text and initialization matrix still required |
| F4 | Public tiny-hint reads with instrumented pending batch: 2,094,081 copied entries and 2,046 indexed visits for 2,048 lines | Reproduced; WP4 repair required. Original fixture failed setup, was corrected, and is not counted as evidence |
| F5 | Generic accumulation path inspected; no scaling measurements yet | Open, WP5 qualification |
| F6 | Public binary read(1) on 16 MiB repeated bytes consumes the whole compressed fixture and retains 16 MiB minus one plaintext byte | Characterized; allocation, limits, latency and concurrent-handle measurements pending |
| F7 | 20,000 immediately ready empty source items; zero sibling ticks before last item, for compression and decompression | Reproduced; WP5 repair required. Tiny/member/cancellation variants pending |
| F8 | Initial trace harness keeps cookies process-local, performs round trips and foreign-handle rejection, and separates diagnostic reads | Initial correction implemented; broader scenario coverage pending |
| F9 | Binary legacy health fields are directly read by text | Confirmed source dependency; use WP6 temporary read-only seam, remove in WP8 |

The in-process F1 fixture cancels only explicitly retained test-owned tasks.
Its thread has a five-second gate watchdog and is released in `finally`.
`tests/test_b2_native_io.py` adds actual runner shutdown in a child process,
with an independent timer to release native work and a parent subprocess timeout.
It also gates a real `io.BufferedReader` read behind aiofiles' normal executor
dispatch. Both added tests reach their intended invariant assertions with
`--runxfail`; no production fixes have been applied.
