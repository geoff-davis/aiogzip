The in-process F1 fixture cancels only explicitly retained test-owned tasks.
Its thread has a five-second gate watchdog and is released in `finally`.
`tests/test_b2_native_io.py` adds actual runner shutdown in a child process,
with an independent timer to release native work and a parent subprocess timeout.
It also gates a real `io.BufferedReader` read behind aiofiles' normal executor
dispatch. At WP0 both added tests reached their intended invariant assertions with
`--runxfail`. WP1 makes both F1 regressions pass; WP2 makes both F2 source regressions pass.
Twelve strict expected failures remain: nine F3 acquisition cases, one F4
pending-line work case, and two F7 fairness cases.

The shutdown child now follows and verifies the parent's import origin, including
an installed wheel when that is what the parent uses. The trace script deliberately
selects checkout source and does not provide installed-wheel qualification.
