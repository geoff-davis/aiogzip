# aiogzip 2.0.0b1 public API decisions

> **Status:** candidate decision record; maintainer approval required before
> the beta tag
>
> **Baseline:** exact `v2.0.0a4`
>
> **Policy:** retain the documented a4 namespace; no runtime behavior change

The exact-a4 snapshot and current housekeeping checkout agree on all 31
top-level exports and all three `aiogzip.codec` exports. No accidental export,
documentation-only name, or material contract discrepancy was found. Every
symbol is retained for the 2.0 line.

In the table, “manifest” means `tests/data/public_api_2_0.json` checked by
`tests/test_public_api_contract.py`; “positive typing” and “negative typing”
mean the shared mypy/ty fixtures in `tests/typing/`.

## Dataclass decisions

- `EngineInfo`: fields remain `compression: str`, `decompression: str`, and
  `crc32: str = "stdlib-zlib"`; frozen, not slotted.
- `GzipMemberInfo`: the exact eleven-field order from a4 is frozen; frozen,
  not slotted.
- `GzipInfo`: `members`, `compressed_size`, and `uncompressed_size` retain
  their order; `member_count` remains a read-only property; frozen, not
  slotted.
- `VerificationResult`: `member_count`, `compressed_size`, and
  `uncompressed_size` retain their order; frozen, not slotted.

Generated `repr()` formatting and private implementation modules are not part
of these decisions.

## Exception decisions

`ConcurrentOperationError` remains public and directly inherits `OSError`.
Context-specific overlap messages remain guidance rather than complete frozen
strings.

The one documented stable message prefix is:

```text
decompressed output exceeded max_decompressed_size
```

Offsets, sizes, member numbers, engine strings, platform details, and other
dynamic exception suffixes are not frozen.

## Overload and protocol decisions

- Conventional binary literals for `open()` and `AsyncGzipFile()` narrow to
  `AsyncGzipBinaryFile`.
- Conventional text literals narrow to `AsyncGzipTextFile`.
- A dynamic `str` mode produces the documented binary/text union.
- `read()`, `write()`, `inspect()`, and `verify()` remain awaitable with their
  documented result types.
- Both chunk helpers return `AsyncIterator[bytes]`.
- Every codec state-changing method returns `CodecOperation`, whose cleanup
  method is statically distinguishable from an ordinary iterator.
- The three `WithAsync*` protocols remain runtime-checkable and structural.

## Deliberate exclusions

The manifest does not freeze private modules or members, internal progress
events, executor and scheduler policy, caches, queues, slots of private
objects, complete dynamic exception text, literal versions, engine diagnostic
strings, example CLI wording, or incidental `repr()` formatting.

No public symbol is removed, deprecated, or newly added by b1. A material
change to any decision above requires the beta escalation rule and a reviewed
plan update.
