## Public-install smoke

A fresh no-cache environment installed `2.0.0a4` from the canonical PyPI
Simple Index rather than from the checkout or a local artifact. Import resolved
from Python 3.14 site-packages, and a public `aiogzip.write()` followed by
`aiogzip.read()` reproduced the original payload.

The configured default `uv` index did not expose the new version immediately;
the canonical PyPI Simple Index did. This was an index propagation difference,
not a package or publication failure.

## Post-release decision

All section 22 criteria pass, including packaging and remote provenance. No
material lifecycle, public-contract, correctness, or performance finding
requires another alpha. Development therefore advances to `2.0.0b1.dev0`.

This development bump does not itself declare the API beta-stable. The package
keeps its Alpha classifier and provisional-codec wording until the actual beta
release-prep, when the beta freeze and documentation changes can be reviewed as
one release-state transition.
