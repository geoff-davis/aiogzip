## 2. Artifact record

Built at `4fd08ff` with `scripts/build_release_artifacts.py`, twice, into
separate evidence directories:

- uv 0.9.22, the version pinned in `publish.yml`;
- `UV_PYTHON` set to the project venv's Python 3.14.2;
- `SOURCE_DATE_EPOCH=1792195200` (2026-10-17 00:00 UTC, the changelog date);
- flit 4.1.0 and twine 7.0.0, from `scripts/release-constraints.txt`.

The two builds are byte-identical:

```text
23d6f840bfa5bc1e89dc63386d94130e1ed3df127e52bee396f317b84b53473c  aiogzip-2.0.0-py3-none-any.whl
71282f83a39fea1e3ae4c40e7fecb0a91e4440679b4d6e8fd71511294244c6b3  aiogzip-2.0.0.tar.gz
```

The sdist's gzip header records maximum compression (XFL 2), as Python
3.14's tarfile writes. Python 3.15 would gzip it differently.
[`releases/v2.0.0.sha256`](../releases/v2.0.0.sha256) was written from the
first build and verified against the second. Each build ran
`twine check --strict` and smoked both installed artifacts.

The wheel's metadata reports `Version: 2.0.0`, `Requires-Python: >=3.11`,
`Development Status :: 5 - Production/Stable` as its only Development Status
classifier, and Python 3.11 through 3.15.
