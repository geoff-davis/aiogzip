## Environment

Captures used CPython 3.12.12 from the checkout `.venv`, uv 0.9.22, stdlib
zlib 1.3.1 at compile time and runtime, zlib-ng 1.0.0, and glibc 2.42. The host
was Linux 6.17.0-41-generic on x86-64 with an AMD Ryzen AI MAX+ 395, 16
physical cores/32 logical cores, and 128 GiB RAM. Full CPU affinity was 0-31;
the governor was `powersave`, boost was enabled, and AC power was present.
Recorded one-minute load ranged from 1.20 to 2.44 across captures.

The checkout is on ZFS. Detached sources and temporary data were on `/tmp`, a
tmpfs filesystem. Raw records contain the exact Python build arguments,
compiler, executable, kernel string, libc, affinity, power-source detail,
load, filesystem, engine, and lockfile values for each run.

Default compression is `stdlib-zlib`; default decompression and CRC32 use
zlib-ng when installed. The stdlib captures forced every operation to stdlib.
The zlib-ng captures verified zlib-ng decompression and CRC32 while preserving
the documented stdlib default compressor; rows opting into fast compression
record zlib-ng independently.

## Capture commands and results

The six core commands used this form, with `SOURCE`, `ENGINE`, and `FILE`
expanded for exact `v2.0.0a3`, locked pre-change main, and exact `v1.11.0`:

```text
.venv/bin/python benchmarks/bench_a3_regressions.py \
  --source-root SOURCE --engine ENGINE --members-mtime-policy POLICY \
  --repeat 5 --memory-repeat 1 --output FILE
```

`POLICY` was `last-header` for the 2.0 sources and `first-header` for
`v1.11.0`, matching each version's public contract. The six supplement
commands used:

```text
.venv/bin/python benchmarks/bench_a4_supplement.py \
  --source-root SOURCE --engine ENGINE --repeat 5 --output FILE
```

The four public-codec release-profile commands used:

```text
AIOGZIP_ENGINE=stdlib .venv/bin/python benchmarks/run_benchmarks.py \
  --category regressions --regression-profile release \
  --regression-mode all --source-root SOURCE --repeat 5 \
  --environment-label LABEL --output FILE

.venv/bin/python benchmarks/run_benchmarks.py \
  --category regressions --regression-profile release \
  --regression-mode all --source-root SOURCE --repeat 5 \
  --environment-label LABEL --output FILE
```

All 16 commands completed sequentially. Core 2.0 records contain 57/57
successful rows. Each v1.11.0 core record contains 45 successful rows and 12
explicitly unavailable public-codec rows. Every supplement contains four
successful rows. Every codec release-profile record contains 58 rows with
five samples per row. No retained capture discarded, interrupted, or excluded
a sample.

The raw records cover the required 64 KiB/64 KiB and 512 KiB/256 KiB chunk
cases, direct one-feed and transport-sized-feed decoding, one-item scheduler
responsiveness, fragmented optional headers, concurrent independent files,
bounded JSONL batches, full binary reads and peak allocation, the complete

## Excluded, interrupted, or invalid runs

No final capture was excluded or invalid. As documented during the `a3`
preflight, benchmark processes that cross aiogzip's decoder-offload threshold
can hang while the managed sandbox shuts down asyncio's default executor. The
credential-free, network-free benchmark commands therefore ran in the
approved local unsandboxed environment. Every final command exited zero and
wrote a complete attested JSON record.
