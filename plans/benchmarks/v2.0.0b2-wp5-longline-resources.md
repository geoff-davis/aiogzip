# WP5 G06 long-line resource comparison

The generic accumulator removes growing-prefix append work on all measured long
lines. This resource-only comparison does not close G06: quiet-machine throughput,
short-line regressions and time-doubling evidence remain outstanding. No production
code changed in this measurement increment. C0 is not pinned.

## Append work and allocation

Charged append work sums the current buffer length plus the appended piece length
at `_append_buffer`. It is a structural proxy, not an allocator-copy count. Final
joins, slices and fast-path construction bypass this hook; zero counts on fast
paths do not mean zero copying. Python allocation peaks include those operations.
Scanning work is distinct: the old generic loop already used an incremental search
offset, while the candidate searches new chunks plus a carried CR.

For newline-free generic reads (`newline=""` and `"\r\n"`), both engines give:

| Logical characters | Baseline UTF-8 / Latin-1 work | Baseline ISO-2022-JP work | Candidate work, all three |
| ---: | ---: | ---: | ---: |
| 1,048,576 | 8,912,896 | 18,350,016 | 1,048,576 |
| 2,097,152 | 34,603,008 | 70,254,464 | 2,097,152 |
| 4,194,304 | 136,314,880 | 274,726,656 | 4,194,304 |
| 8,388,608 | 541,065,216 | 1,086,324,224 | 8,388,608 |
| 16,777,216 | 2,155,872,256 | 4,320,132,096 | 16,777,216 |

Baseline work doubling ratios are 3.882/3.939/3.969/3.984 for UTF-8 and Latin-1,
and 3.829/3.910/3.954/3.977 for ISO-2022-JP. Every candidate ratio is 2.000.
These are work ratios, not time ratios. The existing structural tests remain
CI acceptance checks rather than freezing measured allocation bytes.

For the 16 Mi-character `newline=""` rows, stdlib Python allocation peaks are:

| Fixture / encoding | Baseline peak bytes | Candidate peak bytes |
| --- | ---: | ---: |
| Repeated ASCII / UTF-8 | 50,300,610 | 33,602,426 |
| Repeated Japanese / ISO-2022-JP | 102,860,529 | 69,471,294 |
| Seeded bytes / Latin-1 | 33,975,983 | 33,630,218 |

Both baseline and candidate peak memory scale approximately linearly: generic-mode
UTF-8 peak ratios range 1.968–2.047 on the baseline and 1.949–2.054 on the candidate. Removing
quadratic cumulative copying does not imply that peak memory was quadratic.
The incompressible case especially shows substantially reduced charged copying
without a large peak-memory reduction. Compare within each encoding, since encoded
byte counts and Python string storage differ across encodings. Unlimited line
results still inherently require O(N) memory.

Latin-1 controls have compressed/encoded ratios of approximately 1.00030–1.00032,
comfortably above the asserted 0.99 floor. They span many compressed source reads,
unlike tiny repeated-data gzip fixtures. CR/LF are excluded; other byte-valued
characters remain intact in the stdlib comparison. Short-line allocation peaks
are unchanged on fast paths and increase by only 408–510 bytes on generic paths
in these captures. This says nothing about short-line throughput, which still
needs the quiet-machine comparison.

## Disposition and remaining qualification

Retain the reviewed fragment accumulator. The combined structural tests,
compatibility matrix and resource observations support linear string-building
work while preserving complete lines, cookies, rollback and salvage. No new
line-size limit or demand-bounded binary decoding is introduced.

Tracemalloc excludes native allocations; RSS is before/after, not a peak, and
includes fixture/reference storage allocated before measurement. Rows share a
process and allocator history; returned-line list collection is measured. These
are single observations per case, not statistical allocation guarantees. Baseline
and candidate resource processes overlapped; no timing comparison is drawn from
them. Recorded one-minute load is approximately 0.59–0.89, with 32 CPUs allowed.

G06 still requires quiet-machine interleaved timings, including both generic
short-line modes at the default chunk size and long-line time-doubling ratios.
G07 latency, G08 final evidence, G09/C0 and G17 remain open. The existing overnight
G08 job is unchanged and does not qualify the later accumulator change.

Claude independently reviewed all four captures through Herdr, confirming hashes,
provenance, fixture equality and every quoted number. Its sole clarification was
to scope the peak-ratio ranges explicitly to the generic modes; that wording is
corrected above. Both local full engine suites pass 3,461 tests with one skip
each, and all-file prek passes. These checks do not replace timing qualification.
