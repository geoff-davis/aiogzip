# WP5 G06 and G07 drafts against 2f78925

The maintainer decided that G06 and G07 should measure the committed first-step
candidate 2f78925 rather than 16af1dc. These are non-runnable drafts: no date is
selected, no unit is registered and no benchmark has run.

## Why the candidate moves

From 16af1dc to 2f78925, only `_codec_async.py` and `_streaming.py` change
(+28/−3 lines), and only through the first-step commit itself. The long-line and
fairness work is already in 16af1dc. The first-step commit adds a per-step check
to `_drive_operation`, which file reads and writes also run. G06 readline timings
and G07 first-read latency must therefore measure 2f78925 for the qualified code
to match C0.

This implies a source freeze: no `src/` changes until C0 is pinned. A later
source change would require re-measuring every gate it affects.
