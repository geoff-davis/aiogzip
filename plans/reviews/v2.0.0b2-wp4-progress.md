# WP4 pending-line progress

G05 remains open. Production candidate: `68dc67c`; measurement harness:
`c9c9ec8`; baseline: reviewed WP3 `140e661`. These changes have not been pushed.

## Review correction

The first uncommitted candidate removed bulk transfer for all positive hints.
The maintainer measured a reproducible approximately 25% slowdown in default
`iter_batches()` and correctly rejected closing G05. Their benchmark results
are review evidence, not measurements made by this record's author. The earlier
2,786-pass report preceded the 70 hint cases; the complete suite then contained
2,856 passing cases, one skip, and two expected failures.

The replacement keeps bulk transfer when the remaining hint covers the unread
text-buffer length. Pending lines are a prefix of that unread buffer, so this
is a conservative upper bound computable without visiting any lines. Unlike a
stored batch end, it remains valid when `_append_buffer()` compacts and rebases
the buffer. Buffer replacement drops pending lines, and partial `read()` and
bounded `readline()` invalidate pending state before consuming buffer text.

Every line inspected or copied by the bulk branch is consumed in that call.
The bounded branch likewise visits only consumed lines. Consequently aggregate
line inspections and element copies remain O(N+B), including varying hints and
long lines. No character-based relaxation of the plan's bound is needed, and
no new persistent counter or state restoration obligation is introduced.

## Coverage

The original F4 test is now an ordinary assertion. New instrumentation charges
length inspections, indexed visits, sliced elements, and returned elements,
with a declared bound of six units per line plus two per public call. Alternating
long and one-character lines exercise hints from 1 through 1 MiB and unlimited.
Against baseline source, four of those cases and the original F4 assertion fail;
the other 78 hint/interleaving cases pass.

Public tests cover translated mixed CR/CRLF/LF input, UTF-8/UTF-16, all newline
modes (the generic modes are compatibility controls), whole-line boundaries,
interleaved read/readline/iteration, tell/seek replay, positive-hint transient
rollback, and poisoned-reader complete-line salvage with a partial tail.

The concurrent JSONL integration module now has a 60-second thread watchdog
via the test extra's pytest-timeout dependency. This bounds loops that cannot
receive asyncio cancellation and executor-shutdown hangs. It terminates the
pytest process on expiry, rather than attempting unsafe continuation.
Two identified stale ingest-test processes from the reported deleted scratch
checkout were terminated; unrelated processes were left alone.

bulk ABBA with three samples per case per capture. Source and harness checkouts
were clean, the interpreter and runner were shared, and imported source and
active decompression engine were verified. Input construction, equality checks,
and output hashing are outside timing; returned-list assembly is inside timing.

### Controlled repeat

A targeted repeat used inherited CPU affinity `{0}` for both source processes
(including their executor threads), 15 samples per capture, and ABBA ordering
on each engine. No test suites ran concurrently. Source and harness remained
unchanged. This materially reduced baseline drift:

| Engine/case | First pair | Reverse pair | Baseline drift |
| --- | ---: | ---: | ---: |
| stdlib default batches | -0.07% | +0.11% | +0.08% |
| stdlib 1 MiB | -0.00% | -0.27% | +0.62% |
| stdlib 8 KiB | -26.38% | -26.51% | +0.30% |
| stdlib unlimited | +0.54% | +0.26% | -0.09% |
| zlib-ng default batches | -0.47% | -0.96% | +0.16% |
| zlib-ng 1 MiB | -0.49% | -0.86% | -0.34% |
| zlib-ng 8 KiB | -31.11% | -31.40% | +0.26% |
| zlib-ng unlimited | +1.08% | +2.16% | -0.96% |

This repeat supports recovery of default/large-hint bulk throughput on the
measured JSONL workload, with no attributable change above 5%. It is focused
WP4 evidence, not cumulative release/G17 qualification or a claim about all
workloads. G05 is left open in the ledger for final qualification review.

Final local suites on default and forced-stdlib engines each passed:
**2,879 passed, 1 skipped, 2 xfailed**. All-file prek passed. The nine additional
poisoned-salvage cases account for the increase from 2,870. No hosted CI or
new dependency-floor runs are claimed for this increment.
