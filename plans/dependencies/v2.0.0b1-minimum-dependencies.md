## Exact-floor design

The CI job will build a wheel, install it with `--no-deps`, install exact
runtime floors, assert every installed version with `importlib.metadata`, and
then run from outside the checkout. Its Python 3.11 modes are:

1. base: aiofiles 23.1.0, zlib-ng absent;
2. csv: aiofiles 23.1.0 and aiocsv 1.2.0;
3. fast: aiofiles 23.1.0 and zlib-ng 0.4.0, with zlib-ng active; and
4. fast-forced-stdlib: the same packages with `AIOGZIP_ENGINE=stdlib`.

Latest/unpinned CI remains complementary and is not replaced.

Actual commands, wheel metadata, exact versions, tests, examples, and results
will be appended during WP3. A floor is not marked passing until the isolated
environment proves it.
