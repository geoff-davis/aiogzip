## Behavior exercised

`scripts/smoke_installed_artifact.py` passed for the wheel, the sdist-built
fast install, and the fast install with stdlib forced. Each run checked:

- package and metadata versions, installation location, and declared floors;
- the frozen public API manifest and top-level/`aiogzip.codec` identity;
- binary and text file round trips;
- synchronous codec and standard-library gzip interoperability;
- `compress_chunks()` and `decompress_chunks()`;
- `inspect()` and `verify()` on valid and CRC-corrupt streams;
- CLI version, JSON inspection/verification, and corrupt-stream exit status;
- aiocsv read/write integration;
- tarfile-style header, seek, and payload traversal; and
- wheel/sdist layout and active/forced compression-engine selection.

`scripts/run_maintained_examples.py` then ran both example CLIs and their full
installed-artifact integration suites from `/tmp`. Result:

```text
fragmented transport self-test: passed
concurrent ingest: 3 shards, 120 rows, 6570 bytes, deterministic digest
55 passed in 0.41s
```

Those 55 cases cover success, arbitrary fragmentation, corrupt and truncated
trailers, cancellation, per-shard and dataset limits, atomic publication,
write and cleanup failures, and operation abandonment. Static AST validation
also confirmed that both examples import no `aiogzip._*` module.

The checkout suite after adding the artifact gates passed with `2402 passed,
1 skipped` in 22.20 seconds.
