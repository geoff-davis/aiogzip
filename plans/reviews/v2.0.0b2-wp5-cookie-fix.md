# WP5: unpublished-read cookies

This is a correctness commit before the separate G06 string-building repair.
It closes neither G06 nor a performance gate.

Fast long-line reads and sized reads retain decoded fragments locally until
publication. With no existing shared prefix, tell() used the advanced decoder
frontier, so a cookie obtained during the read skipped unpublished characters.
The fix saves the fragment origin only for that empty-prefix case and makes
tell() use it. Publication clears the origin; reservation exit also clears it
on every exceptional path. Existing buffered-prefix cookies retain their
original behavior, and concurrent tell() remains supported.

The fast-line path reuses its existing decoder snapshot. Sized reads take an
additional snapshot on an empty-buffer refill. Reservation exit gains one
attribute store; ordinary buffered line iteration is unchanged. These costs
need later quiet-machine read/readline qualification. Tonight's G08 job remains
pinned to its reviewed fairness source and does not qualify this increment.

The regression matrix covers readline, anext, sized read, readlines(hint) and
iter_batches, all five newline modes, UTF-8/UTF-16/ISO-2022-JP, both initial and
midstream positions. Midstream setup leaves no decoded prefix and can leave an
incomplete code point or shifted decoder state. Tests compare replayed data,
not opaque cookie representations. Cancellation and injected errors before
binary consumption test recoverable data and origin cleanup.

Before the expanded composite/midstream matrix, Codex ran the new cookie cases
against clean f4ddcf7 source: 33 failed at the replay assertion and 16 passed.
The working tree passed those cases. Claude independently reviewed the patch
through Herdr and ran focused probes including composite APIs and shared-prefix
cases; it found no correctness problems. Its two coverage suggestions became
the composite and midstream matrix. The final focused module passes 154 cases,
with only the two existing G06 copying reproductions still strict xfails.
