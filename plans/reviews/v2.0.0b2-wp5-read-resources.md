# WP5 G07 resource measurement preparation

This increment changes no production code and closes no gate. The file reader
continues draining each codec operation before returning. A small logical read
can therefore inflate and retain much more plaintext than it returns; the codec
output-piece size is not a bound on that aggregate.

## Public compatibility coverage

The existing 42 below/at/above size-limit cases are supplemented by 42 cases
covering binary read, read1, readinto, peek, bounded readline, text read and text
readline on seekable and nonseekable sources. Two members are delivered together,
separately, or with the corrupt final trailer separated from its plaintext. Tests
check early results, mtime advancement, validation failure, explicit salvage and
the subsequent broken-reader error. Two additional cases verify that a failed
readinto leaves its destination unchanged. Private retention sizes are measured,
not frozen as public acceptance criteria.

## Measurement design

`scripts/measure_b2_read_resources.py` provides independent resource and latency
phases. Each of 104 matrix rows runs in a fresh child process with clean committed
source and harness, checked import origin and explicit engine selection. Rows
cover 1/16/32 MiB compressible payloads, seven small-read surfaces, seekable versus
rewind-cached sources, and one versus four independent handles. A seeded random
16 MiB control exceeds one compressed source chunk. Additional rows cover a
1 MiB decompression limit and corrupt trailers against the 16 MiB payload.

Resource mode counts returned inflate bytes, including a possible limit-overflow
byte, separately from codec-accounted bytes. It records each handle's requested
and returned size, source bytes fetched and accepted, retained binary/text data,
compressed cache, validation/metadata state and output-piece bound. Tracemalloc
captures incremental Python allocation around first calls; fixture construction,
hashing, opening and readinto targets precede it. Full content verification follows
measurement. RSS observations are before/after snapshots, not transient peaks;
tracemalloc excludes native allocations. Text uses Latin-1 and LF newline mode
to preserve a direct mapping between characters and fixture bytes.

Latency mode has neither the allocation tracer nor inflation wrapper. Its sibling
ticker and first-result times require quiet-machine qualification. Resource runs
make no timing claims and do not replace that phase. The frozen overnight G08 job
is unchanged.

## Disposition and remaining evidence

Retain the current eager-drain policy for this increment. A demand-bounded file
reader would change validation, metadata and salvage timing and needs a separate
compatibility decision. Existing user guidance explains the tradeoff and advises
bounding decompressed size and concurrent handles.

The harness must be committed before collecting attested captures. Results and
their review belong in a subsequent evidence commit. G07 remains open pending
the resource capture and quiet-machine latency/scheduling evidence; G06, G08,
G09 and G17 are unchanged.
