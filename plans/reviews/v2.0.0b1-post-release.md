## Public-install and integration smoke

A fresh no-cache Python 3.12.12 environment outside the checkout installed
`aiogzip[csv,fast]==2.0.0b1` from the canonical PyPI Simple Index. Import
resolved from the environment's `site-packages`, and the installed-artifact
smoke passed the frozen API manifest, version and dependency metadata, package
namespace, direct codec, async file, streaming, inspection, verification, CLI,
and `aiocsv` paths. zlib-ng 1.0.0 supplied decompression and CRC acceleration;
compression retained the documented stdlib default.

Both maintained examples then passed their command-line self-tests and the
complete success, corruption, truncation, cancellation, limit, and cleanup
suite: 55 tests passed. The first harness invocation had installed `pytest`
but omitted the separately declared `pytest-asyncio` plugin, so pytest refused
to execute 42 async tests after both example commands themselves passed. After
installing that declared test dependency, the unchanged harness passed all 55
tests. This was an isolated test-environment setup error, not a package or
example failure.

## Post-release decision

All beta release, publication, provenance, documentation, artifact, and issue
closeout gates pass. Development advances to `2.0.0b2.dev0` while retaining
the Beta classifier and the frozen 2.0 compatibility contract.

This development version does not promise that a public `b2` is required.
Compatible fixes discovered through beta feedback use the `b2` line. A later
review may proceed directly to `rc1` only if beta feedback and contract
evidence show that no code or public-contract correction is needed; elapsed
time alone is not sufficient.
