# S06 pre-registration: RC2 timing windows

Nothing here has run. On 2026-10-09 the maintainer authorized a window
starting at about 01:00 on 2026-10-10 ("I authorize"). The machine was busy
during the day. Gate S06 of the [2.0.0rc2 plan](../RELEASE_2_0_0RC2_PLAN.md)
times "S02's change on the offload path, and any other hot-path change,
against rc1". Its acceptance criterion is "no unexplained cost above 5%".

The method, the harness and the decision rule are
[R12's](v2.0.0rc1-r12-preregistration.md), unchanged. Only the commits, the
paths and the date differ. R12 already timed rc1's repairs against b2, and its
accepted costs are rc1's baseline here.

## What is measured

| Change | Changed path | Rows that measure it |
| --- | --- | --- |
| S02 (BC18) | `_settle_before_cancel` waits through a private `_completion_waiter` instead of `asyncio.shield`, on every call, cancelled or not | Every offloaded codec step (`_run_in_thread`: compression inputs of 256 KiB or more, decoder inputs of 1 MiB or more): the `io` rows on large files, the `concurrency` and `memory` rows, and the 262,144-byte write sizes. Every path open and every owned native close (`_initial_call`, `_close_underlying`): `rc1_paths.py`'s `open/close x200`, and every runner row that opens and closes a path. `inspect()` and `verify()` open and close through the same code: the `inspection` rows |
| S01 (BC16) | `_finish_abort` holds a cancellation while it closes; the exceptional context exit aborts outside the `except` block | Only exits that abort an active call. No row aborts. The ordinary context exit is unchanged and is timed by every runner row |
| S03 (BC17) | Opening cleanup's note after a cancelled acquisition | Only cancelled opens. No row |
| S04 | Test-only | None |

Every other runner row is also judged, so a cost on an unlisted path is
caught too.

The per-call change is small next to an executor round trip: an uncancelled
call replaces shield's outer future and two callbacks with a waiter future and
two callbacks. A slowdown above noise is therefore not expected. The window
exists to show it.

## Statistics and decision rule

R12's, unchanged. `summarize.py window` refuses any window that R12's rules
refuse. A refused window is rerun whole, and the candidate is never rerun
alone. The primary statistic is each row's minimum of the four capture
medians on each side, with the four adjacent A/B pair deltas.

| Slowdown (B against A, by minimum) | Required action |
| --- | --- |
| 5% or less | None |
| More than 5% | Investigation and a recorded disposition |
| More than 10% and attributable to the candidate | Blocks by default |

The `aa` window reports each row's delta and the largest absolute delta per
engine. It is evidence within an investigation, not a waiver. R12's accepted
costs are rc1's baseline and are not re-litigated; a row above 5% is judged
against `d382f17`, which already carries them. R12 recorded several rows as
noisy (text read on zlib-ng, the CRC salvage `read()` row, small-file
`inspect()`/`verify()`). A flag on one of them still needs a disposition, and
the record says how it compares with R12's `aa` window.

## After the run

`summarize.py window` runs on each results directory. The results, the
harness and the unit logs are archived under
`plans/benchmarks/data/rc2/s06/`. A record follows in `plans/reviews/`, with
any investigation of a row above 5%, and the units are unlinked. S06 closes
only on the maintainer's sign-off.
