install prereleases. A quiet window is weak evidence for that reason, and the

## Waiver: no workload run on rc2

**Waived by the maintainer on 2026-10-17.** No hands-on workload was run on
2.0.0rc2 itself. Between `v2.0.0rc1` and `v2.0.0rc2`, `src/` differs only in:

- `__version__`;
- the three cancellation fixes BC16–BC18, in `_binary.py`,
  `_codec_async.py`, `_inspection.py` and `_opening.py` (with
  `__init__.py`, 5 files, 96 insertions and 63 deletions);
- Python 3.15 support, which added no library code.

BC16 and BC17 change only a cancelled exit abort and an opening cleanup note.
BC18, which removes the Python 3.14 shielded-future log, also changes how
every offloaded call settles: it now waits without `asyncio.shield`, so an
uncancelled call reaches that code too. The ledger tests and the hosted
matrix cover all three. The RC2 timing record
([S06](v2.0.0rc2-s06-record.md)) established no unexplained slowdown above 5%
against rc1. Its one row above 5% is a known bimodal artifact that also flips
in the self-comparison control, and the path open and close became about 5%
faster.

Under the plan's source freeze, 2.0.0's `src/` must equal rc2's apart from
`__version__`. So the rc1 workload result, plus this delta, stands for the
release.
